# C 超个人投研信息层

当投资研究要变成 C 超个体的个人投研推送，而不是普通市场摘要时使用本参考。

## 核心定义

这里的“C 超”指可能拥有 CEO、CFO、CIO 等职业身份，但以**个人身份**阅读投资、理财和财经内容的高认知个体。

职业身份只提供行业理解、商业经验和复杂信息处理能力，**不代表读者正在替公司作经营、预算、供应商、技术采购或资本开支决策**。

一份合格的个人投研产品，要改变的是读者对盈利、现金流、估值、周期、资产暴露、风险或研究优先级的判断，而不是给公司团队布置动作。

## 两个产品，不共用一种文章形态

### Product A｜Daily Scan

用于普通浏览日。多主题、短、可少、可沉默。内部判断可以遵循“新事实 → 投资含义 → 下一关键变量”，但这些标签必须留在后台。读者看到的是结论型标题和一到两段自然财经中文；不要反复印出“发生了什么 / 这意味着什么 / 接下来只看什么”。

Product A 的工作是改变今天该盯什么，不是假装替代个股研报。

### Product B｜Triggered Rolling Deep Read / 变化深读

用于当下出现一个会改变研究判断的新动向。深度来自把这次变化放回历史轨迹，而不是把问题锁得更窄或预测得更远：

```text
当前新信号
→ 调取历史事实、prior 与过去预测
→ 比较这次 delta
→ 解释机制为什么可能不同
→ 判断下一关键事件前的主路径与备选路径
→ 给出研究动作、升级 / 降级信号与证伪条件
```

Product B 不按固定公司、固定问题或固定周频生产。默认 horizon 是下一财报、指引、政策、价格数据、合同兑现等 material event。若关键证据长期缺失，后台继续等待，读者面不反复发布 `HOLD`。AI 可以交叉核对投行、公司、客户供应商和产业链证据，但不复制评级、目标价或交易语言。

### 两者关系

- A 发现并排序当下变化；
- 一个高价值新信号触发 B，B 调取历史而不是从零做长文；
- B 的一个真正改变判断的结论可以压回后续 A；
- 没有新变化时，B 不发；后台记忆与 dashboards 可以继续等待；
- Stock / Question Deep Pack 只在 用户明确提出且资料足够时作为按需专项研究。

## 最小工作流

1. **先建立跨主题候选池。**
   - 宏观与流动性；
   - 公司事件与财报；
   - 行业 / 主题变化；
   - 市场价格与估值；
   - 专家 / 媒体线索；
   - 资产 / 观察名单相关性。
   - AI 基建可以是 pilot，但不是 source universe。

2. **写作前先排序。**
   - source authority
   - freshness
   - evidence change
   - magnitude
   - novelty
   - personal-investment usefulness
   - portfolio / watchlist relevance
   - confidence：verified / probable / weak / watch-only

3. **建立 C 超个人画像。**
   - 职业 / 行业背景：只作理解上下文；
   - 个人投资兴趣；
   - 资产 / 观察名单暴露；
   - 当前 thesis 与开放问题；
   - 风险承受、流动性和研究时间窗；
   - 可信来源偏好；
   - 不值得打扰的主题；
   - 隐私与披露边界。

4. **按个人投资相关性重排。**
   - 市场重要，不等于值得推送。
   - 候选至少要改变盈利、现金流、估值、周期、利润分配、资产暴露或风险中的一个变量。
   - 不把职业背景自动翻译成公司预算、供应商选择、团队问题或内部项目建议。

5. **渲染前比较 topic state。**
   - 保存 `last_summary`、`current_thesis`、`open_questions`、`watch_signals`、`changed_since_last_push`、`kill_signal`、`next_check_date`。
   - 标记 `new / updated_evidence / priority_changed / unchanged / dropped_from_top_pool`。
   - 没有重大变化就不发；不要把昨天的判断重写成今天的发现。

6. **先选产品，再渲染。**
   - Product A：先说最值得重估的判断，把新事实、投资含义和下一关键变量写成自然段；默认 1–4 条，一屏能读完，不为配额凑满。
   - Product B：只在出现 decision-worthy current delta 时触发；读取历史 prior、过去预测与后来结果，解释本次变化，并把走势判断收在下一 material event 前。
   - B 必须给具体研究 / 监控 / 暴露检查动作和可观察证伪条件；没有新变化时不发布。
   - 按需 Stock / Question Deep Pack 仍可检查分部财务桥、资本强度、估值方法和专业研究边界，但不承担默认周更。

## 读者语言

输出应像成熟财经媒体或分析师写给高认知个人投资者的中文：专业、自然、克制，不像数据报告、技术报告或系统回执。

读者表面可以保留：

- 公司名、产品名、ticker；
- 已本土化的常见财经缩写；
- 完整原始来源或新闻链接。

读者表面不得出现：

- 本地路径、文件名、claim ID、证据计数、coverage receipt、quality scan、renderer、schema；
- “问团队”“重算预算”“供应商选择”“内部项目 ROI”等公司行动提示；
- 可自然翻成中文的英文解释句、technical prose 或 jargon；
- 买卖、持有、仓位、目标价或执行建议。

自然形态示例：

> AI 基建已经从订单故事走进利润表，但资本回收还没有完全跟上。对个人投资者，下一步不该继续争论“需求是真是假”，而要比较哪些环节已经形成利润和现金流，哪些环节仍在承担高资本开支与回报延迟。
>
> 如果云业务增速和利润率放缓，而资本开支与折旧继续上升，这个判断就需要下调。

## 实现原则

证据与状态层可以共用，但两个读者产品承担不同工作：

- `source_universe_intake`：把来源压成跨主题候选；
- `cxo_intelligence` / Daily Scan renderer：读取个人画像、排序、渲染并做读者语言扫描；
- `topic_state`：比较本次与上次真正变化；
- `triggered_rolling_deep_read`：以当前重大变化为入口，读取 `topic_state`、历史 claims / forecasts / outcomes，形成 next-event trajectory、研究动作与 falsifiers；
- `stock_question_deep_pack`：仅在用户明确提出、资料足够的按需专项研究，组织投行与公司来源、假设账本、分部财务桥、共识差异与估值审计。

Product A 与 Product B 可以共享证据，但不能共享同一个输出模板。

旧字段名如 `cxo_profile`、`business_exposure` 可以为兼容性暂时保留，但其语义必须转为个人投资兴趣与观察范围，不能继续生成企业行动建议。

## 常见失败

1. **把身份当职责。** C 超身份不是公司决策授权。
2. **正确但无用。** 官方数据、财务快照和例行披露若不改变投资判断，就不应进入简报。
3. **后台泄漏。** 证据链、文件名和验证回执属于后台，不属于读者。
4. **翻译腔与中英混排。** 公司名和必要缩写可保留，英文解释句必须本土化；无法本土化时 fail closed。
5. **技术报告冒充财经分析。** 事实要落到盈利、现金流、估值、周期、利润分配或风险。
6. **没有反证。** 没有降级条件的主题容易变成趋势宣传。
7. **没有状态。** 重复旧判断会制造每日 déjà vu；无变化时沉默。
8. **工程绿灯冒充产品通过。** 测试与扫描只证明 harness；named reader 仍需判断是否自然、是否改变下一问。
9. **把问题收窄、预测拉远冒充深度。** 固定 pair / 窄问题若因为关键披露缺失只能长期 `HOLD`，就留在后台。Product B 必须由当下新变化触发，用历史说明 delta，并把判断落到下一关键事件前。
10. **用摘要冒充投行原文。** 二次媒体可以作为 locator 或公开摘要，但不能被标成已读原始专业报告，也不能支撑“多投行交叉验证已完成”。

## 验证

一次 C 超个人投研运行只有在以下条件满足时才算完成：

- 候选来自不止一个来源主题；
- 个人投资画像确实影响排序；
- 和上次相比的变化已经核对；
- 无重大变化时不推送；
- 读者表面不出现公司行动建议、系统路径、文件名、claim ID、回执或证据计数；
- 英文 prose / jargon gate 为零，只保留允许的名称和缩写；
- 无买卖、持有、仓位、目标价或执行建议；
- 至少一条内容改变盈利、现金流、估值、周期、资产暴露、风险或研究优先级；
- Product A 的工作表逻辑留在后台，读者看到的是自然财经段落；
- Product B 由当下重大 delta 触发，已调取 comparable history / prior，说明这次哪里不同，并把主路径与备选路径收在下一 material event 前；
- Product B 给出具体研究、监控或暴露检查动作及可观察证伪条件；固定长周期缺口没有被反复包装成读者更新；
- 二次媒体与专业原文的访问状态没有混淆；
- 原始来源可追溯；
- named reader 已判断自然度与 human-use value。
